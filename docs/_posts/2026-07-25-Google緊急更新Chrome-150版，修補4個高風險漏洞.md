# 🔥 解析 Google Chrome 高風險漏洞：利用 UAF 和 Out of Bounds Write 進行沙箱逃逸

> **⚡ 戰情快篩 (TL;DR)**
> * **嚴重等級**: High (CVSS 分數：8.8, 8.3, 8.1)
> * **受駭指標**: RCE (Remote Code Execution)
> * **關鍵技術**: UAF (Use After Free), Out of Bounds Write, Heap Spraying

## 1. 🔬 漏洞原理與技術細節 (Deep Dive)
* **Root Cause**: Google Chrome 中的某些函數沒有正確地檢查記憶體邊界，導致了 UAF 和 Out of Bounds Write 的漏洞。例如，當一個物件被釋放後，其記憶體空間可能被其他物件重用，但如果原來的物件仍被引用，就會發生 UAF。
* **攻擊流程圖解**:
  1. 攻擊者創建一個特製的 HTML 網頁，包含惡意代碼。
  2. 用戶訪問該網頁，惡意代碼被執行。
  3. 惡意代碼利用 UAF 和 Out of Bounds Write 的漏洞，進行沙箱逃逸。
* **受影響元件**: Google Chrome 150.0.7871.181 和 150.0.7871.182 版本，適用於 Windows、macOS、Linux 和 Android 平台。

## 4. 📚 專有名詞與技術概念解析 (Technical Glossary)
* **UAF (Use After Free)**: 想像兩個物件同時使用同一塊記憶體空間。技術上是指一個物件被釋放後，其記憶體空間可能被其他物件重用，但如果原來的物件仍被引用，就會發生 UAF。
* **Out of Bounds Write**: 想像一個陣列被寫入超出其邊界的數據。技術上是指寫入數據超出陣列或緩衝區的邊界，可能導致數據損壞或安全漏洞。
* **Heap Spraying**: 想像一個堆疊被填充特製的數據。技術上是指在堆疊中填充特製的數據，以便於利用 UAF 或其他安全漏洞。
