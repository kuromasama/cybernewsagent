# ⚠️ 解析 Google Chrome 151 穩定版的軟導覽與互動內容繪製效能紀錄

> **⚡ 戰情快篩 (TL;DR)**
> * **嚴重等級**: Medium (CVSS 分數：未提供)
> * **受駭指標**: 效能監測資料混在一起，難以準確反映單頁應用程式中的各次軟導覽
> * **關鍵技術**: 軟導覽、互動內容繪製、效能監測

## 1. 🔬 漏洞原理與技術細節 (Deep Dive)
* **Root Cause**: Google Chrome 151 穩定版之前的版本，將單頁應用程式中的各次軟導覽視為同一份網頁，導致效能監測資料混在一起。
* **攻擊流程圖解**: 使用者點選連結 -> JavaScript 進行軟導覽 -> 更新網址與畫面內容 -> 瀏覽器將前後畫面視為同一份網頁 -> 效能監測資料混在一起。
* **受影響元件**: Google Chrome 151 穩定版之前的版本。

## 2. ⚔️ 紅隊實戰：攻擊向量與 Payload (Red Team Operations)
* **攻擊前置需求**: 使用者點選連結，觸發軟導覽。
* **Payload 建構邏輯**:

    ```
    
    javascript
    // 範例指令：使用 JavaScript 進行軟導覽
    window.history.pushState({}, '新頁面', '/new-page');
    
    ```
* **繞過技術**: 無相關繞過技術。

## 3. 🛡️ 藍隊防禦：偵測與緩解 (Blue Team Defense)
* **IOCs (入侵指標)**: 無相關 IOCs。
* **偵測規則 (Detection Rules)**:

    ```
    
    yara
    // 範例規則：偵測軟導覽
    rule soft_navigation {
        meta:
            description = "偵測軟導覽"
            author = "您的名字"
        strings:
            $js_code = "window.history.pushState"
        condition:
            $js_code
    }
    
    ```
* **緩解措施**: 更新 Google Chrome 至 151 穩定版或以上版本。

## 4. 📚 專有名詞與技術概念解析 (Technical Glossary)
* **軟導覽 (Soft Navigation)**: 想像使用者點選連結，網站透過 JavaScript 進行導覽，更新網址與畫面內容，而不重新載入整份網頁。技術上是指使用 JavaScript 進行導覽，更新網址與畫面內容。
* **互動內容繪製 (Interactive Content Painting)**: 想像使用者點選按鈕，網站透過 JavaScript 進行內容繪製，更新畫面內容。技術上是指使用 JavaScript 進行內容繪製，更新畫面內容。
* **效能監測 (Performance Monitoring)**: 想像使用者點選連結，網站透過 JavaScript 進行導覽，更新網址與畫面內容，瀏覽器監測效能資料。技術上是指使用 JavaScript 進行導覽，更新網址與畫面內容，瀏覽器監測效能資料。
